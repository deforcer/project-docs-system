# Работа над Project Docs System

Исходники устанавливаемого скилла находятся в `skills/project-docs-system/`.
Перед изменениями прочитайте README, релевантные references и docs/work-log.md.
Сохраняйте скилл независимым от этого репозитория: ссылки внутри пакета должны
вести только на bundled файлы или явно обозначенные внешние источники.

Меняйте инструкции по наблюдаемым потребностям. Сохраняйте существующие
договорённости целевого проекта; не превращайте шаблоны в обязательные формы.
Для изменения поведения обновляйте сценарии в tests/scenarios.md.
Проверяйте `python3 scripts/validate.py` и применимость сценариев.
Проверки выполняются локально; не добавляйте CI/CD без запроса пользователя.
Результат ручного разбора и фактического выполнения различайте явно.

Существенные изменения фиксируйте в docs/work-log.md и публикуйте в GitHub.
Перед push учитывайте remote; после push проверяйте удалённый commit.
Секреты не должны попадать в файлы и историю Git. Не включайте в скилл
рабочие данные команд, секреты, абсолютные пути автора или локальный контекст.
