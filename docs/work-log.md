## 2026-10-24 — переносимая установка

Причина: README требовал клон в Projects и symlink/Junction, а каталог
установки описывал только Codex. Основным способом стала установка через
агента с определением клиента и ОС. Добавлены marketplace и manifest
Claude Code, установка через Codex skill-installer и ручное копирование
полного пакета в стандартный или настроенный каталог клиента. Структура
проектов и место исходного клона больше не задаются. Обновлены сценарии
установки и обновления; расписания автоматически не создаются.

Проверено: scripts/validate.py; git diff --check; строгая валидация обоих
Claude manifests; регистрация локального marketplace и установка плагина
в user scope с отдельным CLAUDE_CONFIG_DIR во временной папке — плагин
включён, версия 0.1.0. Копии пакета в .agents/skills и .claude/skills
в произвольной временной папке с пробелами проходят standalone-валидатор.
Пакет скилла и методика не менялись. Загрузка инструкций в новой сессии,
установка на Windows и независимые поведенческие сценарии не запускались.

## 2026-10-24 — установка только в текущий клиент

Установочный промпт больше не перечисляет действия для нескольких клиентов
как последовательные поручения. Он выбирает один способ из README по среде
текущего чата и ограничивает установку и проверку этим клиентом. При неизвестном
клиенте предусмотрено уточнение до установки. Добавлены сценарии для компьютера
с двумя клиентами и для неизвестной среды.
Проверено: scripts/validate.py и git diff --check. Поведенческие сценарии
описаны; отдельные прогоны ассистентов не выполнялись.

## 2026-10-27 — минимальный объём и общий контекст, версия 0.2.0

По согласованному разбору скилла уточнён выбор минимального состава: старт

проекта, роль и первая задача не образуют обязательную анкету.

Убраны повторы между входной инструкцией и references, согласованы заготовки.

Проверено: локальный валидатор, git diff --check и оба Claude manifests.
