# Проверка версии 0.1.0

Дата: 2026-10-08. Все данные примеров синтетические; PROD-системы в проверках
поведения скилла не использовались.

## Локальные проверки пакета

- Валидатор skill-creator: frontmatter и инструкции SKILL.md.
- Разбор agents/openai.yaml, длина подписи и наличие имени скилла в prompt.
- scripts/validate.py: комплектность, ссылки, переносимость и характерные данные исходного workspace.
- Та же проверка для отдельной копии только папки скилла.
- Отрицательные примеры валидатора: битая ссылка, ссылка за границу пакета,
  случайно перенесённый абсолютный путь автора.

## Авторское применение к примерам

Примеры созданы автором скилла во временных папках по
[сценариям](scenarios.md); это не независимый запуск другого ассистента.

| Пример | Проверено |
| --- | --- |
| Новый проект разработки | 8 документов, минимальная навигация, критерий CSV-импорта связан с проверкой, продуктовая проверка честно не выполнена |
| Существующий QA-проект | 6 файлов; требования, ADR и пользовательская регрессионная стратегия сохранены побайтно; новые features/decisions не созданы; среда отмечена недоступной |
| Повторное рассмотрение QA | Изменения признаны ненужными; состав и хеши файлов совпали. Это авторская проверка решения, не автоматический повтор агента |
| Некодовый процесс | 5 файлов; SLA сначала открыт, затем уточнён по запросу в процедуре и проверке; исторический результат сохранён; вопрос рабочего календаря остаётся видимым |

Внутренние ссылки трёх примеров проверены программно. Пользовательские файлы
QA и исторический результат некодового примера сравнены по SHA-256.

## Пределы проверки

Независимые поведенческие прогоны ассистента и автоматический выбор скилла
в новой сессии не проверены. Windows Junction описан, но на Windows не запускался.
Проверка ссылок не включает внешние URL и Markdown-якоря.
Организационный пилот и работа примеров приложений не выполнялись.

Установка на macOS выполнена через пользовательский symlink. Чтение SKILL.md
по установленному пути и совпадение с исходником подтверждены. Загрузка скилла в новую сессию остаётся непроверенной.
